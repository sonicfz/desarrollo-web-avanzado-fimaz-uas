Se creo una clase base llamada Usuario que protege los datos esenciales (nombre y correo) y valida el formato del email mediante una Excepción (throw Exception) si el correo es inválido, el proceso se detiene automáticamente a partir de ella se aplicó Herencia para crear las clases Admin y Alumno, donde esta última añade el atributo exclusivo de Matrícula Finalmente, en el archivo index.php se implemento un bloque try/catch que permite intentar la creación de los objetos y capturar errores de validación de forma controlada asegurando que el sistema muestre un mensaje de error amigable en lugar de un fallo total del servidor imprimiendo exitosamente los datos y roles de los usuarios válidos.
