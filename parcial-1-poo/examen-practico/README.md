trata de un sistema de usuarios usando POO la clase principal es Usuario que es la que tiene los datos basicos como el nombre y el correo lo importante aqui es que en el constructor puse una validacion con filter_var; si el correo no tiene cara de correo real, el código lanza un throw (una excepcion) que detiene todo para que no se cree un usuario con datos mal hechos De esa clase "jefa" salen otras dos: Admin y Alumno el Admin solo dice su rol pero el Alumno si tiene algo extra que es su matricula.

En el archivo index.php es donde pasa todo lo visual usé un require_once para jalar las clases y luego meti la creacion de los usuarios dentro de un bloque try/catch. Esto es para que si el tercer usuario el que puse con el correo inventado falla el programa no se muera sino que el catch agarre ese error y lo guarde en una variable al final esa variable la uso para mostrar un aviso rojo arriba de la tabla si algo salio mal la tabla se llena sola con un foreach y lo único arreglado es un if que pregunta si el usuario es un Alumno para mostrar su matricula porque si se la pedimos al Admin el código tronaria ya que ellos no tienen ese dato.
